# Ice Cream Parlor Management System

This is a simple Ice Cream Parlor Management System project developed for learning and practice purposes.

## Project Description
The project helps manage an ice cream shop by handling:
- Ice cream menu
- Customer orders
- Billing system
- Stock management
- Employee details

It is designed to make ice cream shop operations easier and more organized.

## Features
- Add and manage ice cream items
- Customer order management
- Generate bills
- Store customer details
- Simple and user-friendly interface

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## How to Run
1. Download or clone the project
2. Open the project folder
3. Import the SQL file into MySQL
4. Start XAMPP/WAMP server
5. Run the project in browser

## Project Purpose
This project is created for educational and practice purposes.
